# Airport Ticketing Database System

## Project Overview

This project presents the design and implementation of a relational database system for an airport ticketing and e-boarding environment using Microsoft SQL Server and T-SQL.

The database was developed to manage passengers, flights, reservations, tickets, baggage records, airport employees, and additional passenger services. The system was designed following relational database design principles and normalised to Third Normal Form (3NF) to reduce redundancy and improve data integrity.

## Features

- Relational database design and normalisation (3NF)
- Entity Relationship Diagram (ERD)

- Data validation using constraints
- Stored Procedures
- Views
- User Defined Functions
- Triggers

- Passenger and reservation management
